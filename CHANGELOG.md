## [0.1.0-alpha] — 2026-09-12

Первый версионированный предрелиз: вложенная генерация проектов
сотрудников поверх генератора документов.

### Добавлено
- Версия продукта `0.1.0-alpha` (`docxforge.__version__`, `python cli.py --version`).
- Вложенное создание проектов: папки `Сотрудник/Проект` из одного пакетного
  источника через составной шаблон пути `{{поле_сотрудника}}/{{поле_проекта}}`
  (например, `{{фио_сотрудника}}/{{проект}}`).
- `parse_composite_template()` и маршрутизация в `create_projects_from_template()`
  (`docxforge/generate.py`); файл `docxforge_settings.json` для каждого сотрудника.
- Поле составного шаблона с валидацией в форме заполнения; диалог количества
  строк и итог `Создано сотрудников: N, проектов: M`.
- Модульные, интеграционные и E2E-тесты (`tests/test_nested_projects.py`,
  `tests/test_gui_fill_form.py`, `tests/test_version.py`).

### Исправлено
- Составные плейсхолдеры резолвятся через маппинг полей (имя поля → столбец
  таблицы): `{{фио_клиента}}` (Таблица `клиенты`, столбец `фио`) группирует по `фио`.
- Любые пробелы внутри `{{ ... }}` резолвятся; папки больше не создаются с
  буквальными именами `{{ ... }}` (откат на значение из таблицы с предупреждением).

## [0.0.0-pre-alpha] — 2026-09-03 – 2026-09-11

Неверсионированный период становления проекта: от пустого репозитория до
готового генератора документов с режимом создания проектов.

### Добавлено
- 03.09 — каркас: `.gitignore`, `.env.example`, pre-commit hook
  (pytest + trufflehog3), `AGENTS.md`/`CLAUDE.md`, README.
- 04.09 — спеки движка шаблонов и DSL (итерации вплоть до v5 по итогам
  пользовательского тестирования); прототип XML-run слияния (0 потерь);
  движок v1 (`schema`, `parser`, `renderer`, `data_reader`), GUI
  (main/project/fill_form), CLI (`create/scan/configure/render/list/info`), тесты.
- 05.09 — пакетные режимы `CONSTANT/SEQUENTIAL/CIRCULAR` с resume;
  разбиение монолитов (`render_loop`/`render_execute`, пакет `cli`,
  миксины `fill_form/`); вставка изображений; сканирование колонтитулов.
- 07.09 — `generate_project()`, вынос UI-строк в `strings.py`, 12 задач по GUI
  (окно на весь экран, «продолжить с последней строки», обработка ошибок,
  логирование), GUI-тесты на pytest-qt.
- 09–10.09 — удаление шаблонов с подтверждением, переименование в «Станок»,
  `directory_template`, сохранение форматирования и переносов строк,
  генерация проектов с шаблонами каталогов.
- 11.09 — `PLAN.md`/`SPEC.md`, двунаправленная синхронизация счётчиков,
  последние шаблоны в недавних проектах, папка вывода `Результат`,
  формат «месяц» для `today`, кнопки вставки полей.
- 11–12.09 — режим «Создать проекты из шаблона» (7 фаз: UI, движок
  `create_projects_from_template()`, резолвинг имён папок, тесты).

### Исправлено
- Порядок текста при слиянии run'ов, `AttributeError`/`PermissionError` в окнах,
  кодировка pre-commit hook под Windows, восстановление `generate_cli`,
  моки дат в тестах ради воспроизводимости.
