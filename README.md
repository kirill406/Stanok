# FirstAgent

## Управление секретами

Файлы `.env` (с реальными ключами/паролями) исключены из git через `.gitignore`.
Для примера доступных переменных смотри `.env.example`.

### Проверка секретов перед коммитом

Перед каждым коммитом автоматически запускается **trufflehog3** — сканер, который
ищет ключи, токены и пароли в коде.

Если секрет найден — коммит будет отклонён.

#### Установка pre-commit hook (после git clone)

```bash
cp scripts/pre-commit.hook .git/hooks/pre-commit
```
(или просто запусти `scripts/install-hooks.bat`)

#### Обход проверки (только если уверен)

```bash
git commit --no-verify -m "сообщение"
```

### Как добавлять новые секреты

1. Открой `.env` — добавь новую переменную (например `MY_API_KEY=abc123`)
2. Открой `.env.example` — добавь ту же переменную, **но без значения**: `MY_API_KEY=`
3. В коде читай переменные через `os.getenv("MY_API_KEY")` или `process.env.MY_API_KEY`
4. Сделай коммит — trufflehog3 проверит, что реальный ключ не попал в git
