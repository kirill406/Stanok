# Паритет CLI ↔ GUI (M15, 001-review)

Таблица соответствия опций CLI (`cli.py`) и GUI (главное окно, окно проекта,
диалог заполнения, диалог поля). Статус на `fix/001-review-findings`.

| Возможность | CLI | GUI | Статус |
|---|---|---|---|
| Создать проект | `create` | Главное окно → «Создать» | OK |
| Сканировать шаблон | `scan` | Окно проекта (список плейсхолдеров) | OK |
| Поле constant/table/counter/today/image | `configure --field --field-type` | Диалог поля | OK |
| Циклы (таблицы) | `configure --cycle` | Диалог заполнения, advanced-секция | OK |
| Агрегации | `configure --aggregation` | Advanced-секция | OK |
| Рендер одного шаблона | `render` | Диалог заполнения → «Создать» | OK |
| Пакетный рендер `--batch` | `render --batch` | Batch-секция | OK |
| Создание проектов (flat/composite) | нет | Чекбокс + шаблон пути + диалог кол-ва | GAP — только GUI |
| Шаблон имени папки | нет | `edit_folder_name_template` | GAP — только GUI |
| Выбор строк (single_row) | нет | Диалог выбора строк | GAP — только GUI |
| Список шаблонов/данных | `list`, `list --data` | Главное окно / окно проекта | OK |
| Сводка проекта | `info` | Окно проекта | OK |
| Отмена долгой генерации | нет (Ctrl+C) | M10: кнопка отмены в прогрессе | Частично |

Правила кодов выхода CLI (M14): `0` — успех, `2` — ошибка использования
(нет `--field-type`, плохой `--start`/`--multiplier`), `1` — runtime
(нет проекта/шаблона, неизвестный тип поля). Ошибки — в stderr,
результат — в stdout.
