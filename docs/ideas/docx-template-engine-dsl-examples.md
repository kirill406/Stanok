# DSL v4 — примеры шаблонов

## Пример 1: Договор поставки (один документ)

Шаблон договор_поставки.docx:

```
ДОГОВОР ПОСТАВКИ № {{ номер }}

г. Москва, «{{ today:dd }}» числа «{{ today:MM }}» месяц «{{ today:yyyy }}» г.

{{ организация }}, именуемое в дальнейшем «Поставщик», в лице {{ @поставщик.должность }} 
{{ @поставщик.фио }}, с одной стороны, и {{ @клиенты.название }}, именуемое в дальнейшем 
«Покупатель», в лице {{ @клиенты.должность }} {{ @клиенты.фио }}, с другой стороны, 
заключили настоящий Договор о нижеследующем:

1. ПРЕДМЕТ ДОГОВОРА

Поставщик обязуется поставить, а Покупатель — принять и оплатить следующие товары:

{# строка in @спецификация }
{{ строка.наименование }}    {{ строка.количество }}    {{ строка.цена }} руб.
{#/}

Итого: {{ sum(@спецификация.цена) }} руб.
С НДС (20%): {{ sum(@спецификация.цена) * 1.2 }} руб.

{{ image:логотип }}
{{ image:подпись:подпись_директора.png }}
```

YAML договор_поставки.yaml:

```
template: договор_поставки.docx
data: данные/
tables:
  поставщик: сотрудники
images:
  логотип: assets/logo.png
  подпись: assets/signatures/
defaults:
  номер: 1
  организация: ООО «Рога и копыта»
output: output/
```

GUI-диалог при генерации:

- **Один документ** / ☑ Несколько — по строкам [клиенты ▼]
- номер: [1] авто ☑
- организация: [ООО «Рога и копыта»] (предзаполнено из defaults)
- @клиенты: [ООО «Альфа» ▼] (выбор строки)
- @поставщик: [Иванов И.И. ▼] (выбор строки из таблицы «сотрудники»)
- логотип: [logo.png 📎]
- подпись: [подпись_директора.png 📎]

## Пример 2: Приказы по сотрудникам (пакетная генерация)

Шаблон приказ_увольнение.docx:

```
ПРИКАЗ № {{ номер }}

от {{ today:dd.MM.yyyy }}

Об увольнении {{ @сотрудники.фио }}, табельный номер {{ @сотрудники.табельный_номер }},
из отдела {{ @сотрудники.отдел }}, с должности {{ @сотрудники.должность }},
с «{{ @сотрудники.дата_увольнения:dd.MM.yyyy }}» г.

Основание: {{ @сотрудники.основание }}

Руководитель: {{ руководитель }}
{{ image:подпись }}
```

YAML приказ_увольнение.yaml:

```
template: приказ_увольнение.docx
data: данные/сотрудники.xlsx
images:
  подпись: assets/signature_director.png
defaults:
  руководитель: Иванов А.Б.
output: output/приказы/
```

GUI-диалог:

- ☑ Несколько — по строкам [сотрудники ▼] → 47 документов
- номер: [1] авто ☑ (начнёт с 1)
- руководитель: [Иванов А.Б.] (предзаполнено)
- today: скрыто (автоматически)
- @сотрудники: «из очередной строки» ✓
- подпись: [signature_director.png 📎]

Результат: 47 файлов с именами 2026_приказ_0001_Сидоров_К.Л.docx, 2026_приказ_0002_Петров_М.Н.docx и т.д.

## Пример 3: Договор с поручителем (алиасы)

Шаблон договор_с_поручителем.docx:

```
Договор займа № {{ номер }}

Займодавец: {{ @займодавец.название }}, ИНН {{ @займодавец.ИНН }}
Заёмщик: {{ @заёмщик.название }}, ИНН {{ @заёмщик.ИНН }}
Поручитель: {{ @поручитель.название }}, ИНН {{ @поручитель.ИНН }}
```

YAML:

```
template: договор_с_поручителем.docx
data: данные/контрагенты.xlsx
tables:
  займодавец: контрагенты
  заёмщик: контрагенты
  поручитель: контрагенты
output: output/
```

GUI: три выпадающих списка — все из таблицы «контрагенты», но три разные строки.

## Пример 4: Поиск по значению (VLOOKUP)

Шаблон:

```
Справка

Контрагент: {{ @клиенты[ИНН=7712345678].название }}
Адрес: {{ @клиенты[ИНН=7712345678].адрес }}
```

Движок сам найдёт строку с ИНН=7712345678 и подставит название и адрес. GUI не показывает список — значение задано прямо в шаблоне.

## Пример 5: Конкретная строка по номеру

Шаблон:

```
Ставка рефинансирования: {{ @ставки[1].значение }}%
```

Первая строка таблицы «ставки», столбец «значение».
