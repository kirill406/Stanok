## Критерии успеха теста v5

| Метрика | Цель |
|---|---|
| Поля заменены на {{ }} | ≥90% |
| Имена осмысленные | ≥80% |
| НЕТ попыток написать @, точку, циклы, sum() | 100% (ни одной) |
| Время выполнения | ≤10 минут |
| Уверенность (вопрос 6) | ≥4 из 5 |
| Комфорт (вопрос 7) | ≥4 из 5 |

Если все критерии достигнуты — v5 работает. Если есть попытки написать @ или sum() — инструкция недостаточно ясна, нужно доработать формулировки.
