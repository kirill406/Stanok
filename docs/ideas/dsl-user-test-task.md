# Задание для участника

## Описание

Перед вами документ Word «Договор поставки» — это обычный текст без разметки. И перед вами Excel-файл с тремя листами:

1. **клиенты** — название, ИНН, адрес, должность_руководителя, фио_руководителя
2. **спецификация** — наименование, количество, цена
3. **сотрудники** — фио, должность

Ваша задача — заменить выделенные **ЖИРНЫМ КУРСИВОМ** фрагменты в документе на разметку по инструкции, чтобы программа могла подставлять данные автоматически.

---

## Текст документа (для справки — разметку ставьте прямо в Word)

*Жирным курсивом* выделены места, которые нужно заменить разметкой.

---

ДОГОВОР ПОСТАВКИ № ***1***

г. Москва, «***04***» ***сентября*** ***2026*** г.

***ООО «Рога и копыта»***, именуемое в дальнейшем «Поставщик», в лице ***Генерального директора*** ***Иванова Ивана Ивановича***, с одной стороны, и ***ООО «Альфа»***, именуемое в дальнейшем «Покупатель», в лице ***Директора*** ***Петрова Петра Петровича***, с другой стороны, заключили настоящий Договор о нижеследующем:

1. ПРЕДМЕТ ДОГОВОРА

Поставщик обязуется поставить, а Покупатель — принять и оплатить следующие товары:

| Наименование | Количество | Цена |
|---|---|---|
| ***Товар А*** | ***10*** | ***1000*** |
| ***Товар Б*** | ***5*** | ***2000*** |

Итого: ***15000*** руб.
С НДС (20%): ***18000*** руб.

Реквизиты Покупателя:
ИНН: ***7712345678***
Адрес: ***г. Москва, ул. Примерная, д. 1***

Подписи:

Поставщик: ***Иванов И.И.***
***[подпись]***

Покупатель: ***Петров П.П.***
***[печать]***

---

## Подсказки

- Номер договора — это порядковый номер документа
- Дата договора — текущая дата при генерации
- Данные о Покупателе (ООО «Альфа», ИНН, адрес, директор) — из листа «клиенты»
- Данные о Поставщике (ООО «Рога и копыта», директор) — из листа «сотрудники»
- Строки товаров — из листа «спецификация», это повторяющийся список
- Итого и НДС — вычисляются автоматически из спецификации
- [подпись] — это изображение
- [печать] — это изображение
