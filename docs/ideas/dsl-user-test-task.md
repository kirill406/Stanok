# Задание: Администратор размечает шаблон (v5)

## Описание

У вас роль Администратора. Перед вами:

- Документ Word «Договор поставки» — обычный текст без разметки
- Инструкция по разметке — 1 страница

Ваша задача — заменить выделенные **ЖИРНЫМ КУРСИВОМ** фрагменты на разметку {{ поле }} по инструкции.

**Важно:** придумайте осмысленные имена полей. Например, вместо «ООО Альфа» напишите {{ название_клиента }}. Чем понятнее имя — тем легче пользователю будет потом настраивать документ в программе.

---

## Текст документа

*Жирным курсивом* выделены места, которые нужно заменить разметкой.

---

ДОГОВОР ПОСТАВКИ № ***1***

г. Москва, «***04***» ***сентября*** ***2026*** г.

***ООО «Рога и копыта»***, именуемое в дальнейшем «Поставщик», в лице ***Генерального директора*** ***Иванова Ивана Ивановича***, с одной стороны, и ***ООО «Альфа»***, именуемое в дальнейшем «Покупатель», в лице ***Директора*** ***Петрова Петра Петровича***, с другой стороны, заключили настоящий Договор о нижеследующем:

1. ПРЕДМЕТ ДОГОВОРА

Поставщик обязуется поставить, а Покупатель — принять и оплатить следующие товары:

| Наименование | Количество | Цена |
|---|---|---|
| ***Товар А*** | ***10*** | ***1000*** |
| ***Товар Б*** | ***5*** | ***2000*** |

Итого: ***15000*** руб.
С НДС (20%): ***18000*** руб.

Реквизиты Покупателя:
ИНН: ***7712345678***
Адрес: ***г. Москва, ул. Примерная, д. 1***

Подписи:

Поставщик: ***Иванов И.И.***
***[подпись]***

Покупатель: ***Петров П.П.***
***[печать]***

---

## Подсказки

- Номер договора — порядковый номер (специальное поле)
- Дата — текущая дата (специальное поле)
- Месяц прописью — тоже дата, но другой формат
- Название организации-поставщика — будет константой («ООО Рога и копыта»)
- Директор поставщика — из таблицы сотрудников
- Название клиента — из таблицы клиентов
- ИНН и адрес — из той же таблицы клиентов (НЕ нужно указывать это в шаблоне)
- Строки товаров (Товар А, Б) — повторяющийся список (НЕ нужно писать цикл)
- Итого и НДС — автоматические расчёты (НЕ нужно писать формулы)
- [подпись] и [печать] — изображения
