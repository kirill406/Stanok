# Вложенная генерация проектов (Сотрудник → Проекты)

Graduated from `specs/000-pre-alpha/` (Status: done).

## Что это
Из одного пакетного источника (колонки сотрудника + проекта) строится
двухуровневая структура: папка сотрудника → папки его проектов.

## Как устроено
- Составной шаблон пути `{{поле_сотрудника}}/{{поле_проекта}}` задаёт вложенность
  (`parse_composite_template()`; пробелы внутри `{{ }}` допустимы).
- Строки группируются по значению колонки сотрудника.
- Папка сотрудника содержит `docxforge_settings.json` (имя + список проектов).
- Папка проекта: копия `Данные/` без изменений, шаблон в `шаблоны/`, пустая
  `результат/`, `<имя>.docxforge` рядом с ними (TABLE → CONSTANT, COUNTER
  сброшен, пакетные источники → CONSTANT). При открытии конфиг мигрирует в
  `~/.docxforge`, исходник из папки удаляется.
- Итог пользователю: «Создано сотрудников: N, проектов: M».

## Точки входа (`src/docxforge/generate.py`)
- `create_projects_from_template()` — маршрутизатор (flat / nested).
- `create_nested_employee_projects()` — ядро: группировка, копирование, конфиги,
  откат при ошибке.
