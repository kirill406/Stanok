# Intent: Python Docx-шаблонизатор

- **Outcome:** Python-шаблонизатор .docx: стандартные шаблоны + данные из таблиц/директорий -> готовый документ в пару кликов
- **User:** Сотрудники одного отдела, 10-50 типов документов у каждого
- **Why now:** Ручной ввод и поиск по разрозненным таблицам отнимают время; шаблоны разъезжаются -> лавина правок
- **Success:** Время на документ с многих минут до пары кликов; правки под стиль к нулю
- **Constraint:** Вариативность: шаблоны и логика подстановки должны легко меняться без переписывания ядра
- **Out of scope:** Не веб-приложение, не документооборот с маршрутами согласования, не коллаборативное редактирование
