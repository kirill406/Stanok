## Non-overlap contract
Каждый блок работает только в своей зоне; общие файлы трогать по минимуму и
только с `git pull` + мелкими коммитами:
- B1: `generate.py` (создание проектов), project I/O.
- B2: logging setup.
- B3: fill-form entry points.
- B4: GUI таблиц + флаги копирования.
- B5: главное меню + recent storage.
- B6: engine counter path.
- B0: только чтение + фиксация (без кода, либо micro-fix отдельной веткой).
