## 1. Назначение

Один модуль — `src/stanok/gui/strings.py` — со всеми пользовательскими
строками приложения (CLI, GUI, тексты ошибок). Ноль кириллических строковых
литералов в `src/` вне этого модуля. Правка формулировки — в одном месте,
ревью — одним файлом.

NFR-3 (`spec.md`): «Русскоязычный интерфейс (все строки через STRINGS)».

---

## 2. Архитектурные решения

### 2.1 Модуль

```python
# src/stanok/gui/strings.py
class S:
    """Все пользовательские строки. Использование: from stanok.gui.strings import S."""

    APP_DESCR = "Генерация docx из проекта"
    ...
    GEN_RESULT_DIR = "Результат"
    ERR_TEMPLATE_FILE = "Файл шаблона не найден: {path}"
```

- Плоский класс `S`, ключи `SCREAMING_SNAKE_CASE`, префиксы по области:
  `APP_` (CLI), `SCH_` (схема/валидация), `TBL_` (таблицы),
  `GEN_` (генерация), `ERR_` (общие ошибки).
- Плейсхолдеры `{name}` + `.format()` на месте использования.
- Тексты переносятся **дословно** (без переформулировок), чтобы не сломать
  поведение и ожидания тестов.
- `gui/__init__.py` — пустой, без Qt и тяжёлых импортов
  (правило: `__init__` без side effects; Qt подтянется в 008+).
- Комментарии/docstrings на русском **остаются** (AGENTS.md разрешает) —
  запрет только на строковые литералы.

### 2.2 Инвентарь переноса (19 литералов, `main` на момент спеки)

| Откуда | Что | Ключ |
|--------|-----|------|
| `app.py` | help-строки argparse (5), итоги прогона, `генерация прервана` | `APP_*` |
| `schema.py` | `Формат версии…`, `путь должен быть относительным…` | `SCH_*` |
| `generate.py` | `Результат` | `GEN_RESULT_DIR` |
| `tables/excel.py` | 4 сообщения `TableReadError` | `TBL_*` |

Не трогаем: docstrings (`schema.py:194,212`, `protocols.py:9`),
фикстуры и тесты-данные (`tests/` вне скана).

### 2.3 Потребители

- `app.py`: argparse/print/logging → `S.*`, снять `# TODO(007)`.
- `schema.py`, `generate.py`, `tables/excel.py`: сообщения исключений → `S.*`.
- Тесты с `match=` на русские тексты → матчить через `S.КЛЮЧ`
  (не дублировать литералы в тестах).

## 4. Тестирование

Файл: `tests/gui/test_strings.py`.

| Сценарий | Ожидаемое поведение |
|----------|---------------------|
| Импорт `S` без Qt и side effects | `import stanok.gui.strings` не тянет PyQt |
| Все ключи — непустые строки | `all(isinstance(v, str) and v ...)` |
| Плейсхолдеры валидны | `Formatter().parse` без ошибок, `.format()` с тестовыми kwargs |
| AST-скан `src/*.py` (кроме `strings.py`) | ноль `Constant`-строк с кириллицей |
| Регрессия: полный `pytest tests/ -q` | зелёные после замены литералов |

## 6. Риски

| Риск | Митигация |
|------|-----------|
| Дословный перенос сохраняет неудачные формулировки | Правки текстов — отдельной задачей после 007, одним diff |
