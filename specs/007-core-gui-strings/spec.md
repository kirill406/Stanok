## 1. Назначение

Единый модуль строк для всего приложения (GUI, CLI, логи, ошибки).
Цель: исключить хардкод строк, централизовать переводы/правки, обеспечить консистентность.

---

## 2. Архитектура

```python
# src/stanok/gui/strings.py
class STRINGS:
    # UI labels
    BTN_GENERATE = "Сгенерировать"
    BTN_CANCEL = "Отмена"
    BTN_BROWSE = "Обзор..."
    
    # Messages
    MSG_PROJECT_OPENED = "Проект открыт: {name}"
    MSG_GENERATION_STARTED = "Генерация запущена..."
    MSG_GENERATION_COMPLETED = "Готово: создано {count} документов"
    MSG_GENERATION_FAILED = "Ошибка генерации: {error}"
    
    # Errors
    ERR_NO_TEMPLATE = "Шаблон не выбран"
    ERR_NO_DATA_SOURCE = "Источник данных не выбран"
    ERR_PROJECT_NOT_FOUND = "Проект не найден: {name}"
    ERR_COUNTER_OVERFLOW = "Переполнение счётчика {name}: максимум 999"
    
    # Tooltips
    TT_TEMPLATE = "Выберите шаблон документа"
    TT_DATA_SOURCE = "Выберите файл с данными"
    TT_MAX_DOCS = "Максимальное количество документов (0 = без лимита)"
```

---

## 2. Правила использования

1. **Никаких строк в коде** — все строки через `STRINGS.NAME`
2. **Именование**: `SCREAMING_SNAKE_CASE`, группировка по префиксу (`BTN_`, `MSG_`, `ERR_`, `TT_`)
3. **Форматирование**: f-строки внутри значений, подстановка через `.format()` в коде
4. **Тесты**: `tests/gui/test_strings.py` — проверка наличия всех ключей

---
