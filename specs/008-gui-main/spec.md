## 1. Назначение

Окно 1 — входная точка GUI: список недавних проектов, быстрый запуск
генерации по каждому, массовый запуск всех, заглушка настроек приложения.
Клик по проекту открывает окно 2 (009). Бизнес-логики ноль: вызовы
`generate_documents` идут через `GenerateWorker` (QThread, как в v0.1).

---

## 2. Архитектурные решения

### 2.1 Макет окна 1

```
┌ Станок ─────────────────────────────────┐
│ Проект А                    [Сгенерировать] │
│ Проект Б                    [Сгенерировать] │
│ ...                                     │
│ [ Сгенерировать все ]  [ Настройки ]    │
│ Статус: <statusbar>                     │
└─────────────────────────────────────────┘
```

- Строка проекта: имя (папка + конфиг) + кнопка «Сгенерировать»
  (прогон всего проекта дефолтными параметрами).
- Клик по строке (не по кнопке) → окно 2 (модальный `QDialog`, 009).
- «Сгенерировать все» — зелёная; прогоняет проекты списка **последовательно**,
  итог — один диалог: создано/пропущено/ошибок по каждому + суммарно.
  Ошибка одного проекта не прерывает остальные.
- «Настройки» — диалог-заглушка (`QMessageBox::information`, текст
  `MAIN_SETTINGS_STUB`); наполнение — вне скоупа.
- Прогресс одиночного/массового прогона — `QProgressDialog` + отмена
  (кооперативная, через `progress`-колбэк 006/008-v0.1).

### 2.2 Worker и ошибки

Без изменений от v0.1: `GenerateWorker` (сигналы
`progressed/finished/failed`), ошибки конфигурации — `QMessageBox`,
окно живо (FR-10). Все строки — ключи `MAIN_*` (007).

### 2.3 Зависимости

`PyQt5==5.15.11` (+ `PyQt5-Qt5==5.15.2` на win32), тесты — offscreen.
`app.main` без аргументов → окно 1; с `project_ref` → CLI (006).

## 4. Тестирование

Файл: `tests/gui/test_main_window.py` (offscreen).

| Сценарий | Ожидаемое поведение |
|----------|---------------------|
| Открытие с tmp-store | строки recent отображены, кнопки на месте |
| «Сгенерировать» у проекта | worker завершён, docx в `Результат/` |
| «Сгенерировать все» (2 проекта) | оба прогнаны, сводный диалог показан |
| Один проект битый | остальные прогнаны, ошибка в сводке |
| Клик по строке | открыт диалог окна 2 (замокать) |
| «Настройки» | диалог-заглушка, без падений |

2. `pytest tests/ -q` — все зелёные.
3. Ручной прогон окна 1 на Windows.
4. Pre-commit чистый, CHANGELOG — запись о фиче 008.

## 6. Риски

| Риск | Митигация |
|------|-----------|
| Массовый прогон долгий, GUI скучает | Прогресс с именем текущего проекта + отмена между проектами |
| Реализация v0.1 (одно окно) устарела | Рефакторинг `MainWindow` под §2.1 входит в фичу, тесты переписываются |
| Пустой recent при первом запуске | Пустой список + подсказка через «Обзор» (009/выбор папки) |
