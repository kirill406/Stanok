# Спецификация: 009-gui-project — Окно 2: проект и шаблоны (FR-13)

**Статус:** Active
**Версия:** 0.1.0
**Фаза:** 2 (GUI)
**Зависит от:** 008-gui-main (окно 1, worker), 006-core-generate, 007-gui-strings
**FR:** FR-13
**NFR:** NFR-3

---

## 1. Назначение

Модальный диалог проекта (открывается кликом из окна 1): название проекта,
пути данных/шаблонов (чтение), таблица шаблонов — имя, количество документов
(spin, 0 = без лимита), кнопка «Сгенерировать» на каждый шаблон. Клик по
шаблону открывает окно 3 (010).

---

## 2. Архитектурные решения

### 2.1 Макет

```
┌ Проект: <имя> ─────────────────────────┐
│ Данные: <путь>  Источник: <файл>       │
│ ┌ Шаблон ───┬ Кол-во ┬ ─────────┐      │
│ │ Договор   │ [ 10 ] │ [Сгенерировать] │
│ │ Акт       │ [  0 ] │ [Сгенерировать] │
│ └───────────┴────────┴─────────────┘   │
│                        [ Закрыть ]     │
└────────────────────────────────────────┘
```

- `ProjectDialog(project_ref, store, parent)` — `QDialog`, модальный.
- PJ читается через `store.resolve_project` при открытии; повторов чтения нет.
- Количество — состояние окна (сессия, в PJ не пишется); применяется как
  `max_docs` в `GenerateCommand(template=имя, max_docs=N or None)`.
- «Сгенерировать» у шаблона — тот же `GenerateWorker` + прогресс/отмена,
  итог — `QMessageBox`, диалог жив (FR-10).
- Клик по строке шаблона → окно 3 (010, модально) для этого шаблона.
- Все строки — ключи `PROJ_*` в `STRINGS`.

## 3. Требования к реализации

| ID     | Требование                                               | Приоритет   |
|--------|----------------------------------------------------------|-------------|
| PROJ-1 | Шапка: имя, пути, источник (только чтение)               | Must        |
| PROJ-2 | Таблица шаблонов: имя, spin кол-ва, кнопка на шаблон     | Must        |
| PROJ-3 | Прогон шаблона через `GenerateWorker` (max_docs из spin) | Must        |
| PROJ-4 | Клик по шаблону → окно 3                                 | Must        |
| PROJ-5 | Строки — `PROJ_*`, AST-охранник зелёный                  | Must        |
| PROJ-6 | Убрать заглушку окна 2 из окна 1                         | Must        |
