## 1. Назначение

Модальный диалог редактирования полей выбранного шаблона (открывается
кликом из окна 2). Значения живут в состоянии окна до закрытия; кнопка
«Сохранить» пишет их в PJ; закрытие с несохранёнными правками спрашивает
«Сохранить?».

---

## 2. Архитектурные решения

### 2.1 Макет

```
┌ Шаблон: <имя> ───────────────────────┐
│ Поле        │ Источник │ Значение    │
│ ФИО         │ таблица  │ [preview]   │
│ Сумма       │ константа│ [  edit  ]  │
│ Номер       │ счётчик  │ [last=41]   │
│ Дата        │ today    │ [2026-10-09]│
│ [ Сохранить ]           [ Закрыть ]  │
└──────────────────────────────────────┘
```

- `FieldsDialog(project_ref, template_name, store, parent)` — `QDialog`.
- Редактируются только `constant`-поля (line edit); остальные — readonly
  с превью (первая строка источника / текущий `last` / сегодня).
- «Сохранить»: константы → `pj.templates[name].fields[*].value` +
  `store.save(pj)`; dirty-флаг сбрасывается.
- Закрытие при dirty: `QMessageBox.question` «Сохранить?» —
  Save (сохранить и закрыть) / Discard (закрыть без сохранения) / Cancel
  (остаться). Текст вопроса — ключ `FLD_DIRTY_ASK`, кнопки — стандартные
  `QMessageBox::Save|Discard|Cancel` (их переводить не надо — берёт Qt).
- Все строки — ключи `FLD_*` в `STRINGS`.

---

## 3. Требования к реализации

| ID    | Требование                                              | Приоритет   |
|-------|---------------------------------------------------------|-------------|
| FLD-1 | Таблица полей: имя, источник, значение/превью           | Must        |
| FLD-2 | Правка constant-полей, остальные readonly               | Must        |
| FLD-3 | «Сохранить» пишет константы в PJ (`store.save`)         | Must        |
| FLD-4 | Закрытие при dirty → «Сохранить?» (Save/Discard/Cancel) | Must        |
| FLD-5 | Строки — `FLD_*`, AST-охранник зелёный                  | Must        |

## 4. Тестирование

Файл: `tests/gui/test_fields_dialog.py` (offscreen).

| Сценарий                                | Ожидаемое поведение               |
|-----------------------------------------|-----------------------------------|
| Открытие, правка константы, «Сохранить» | PJ в Home обновлён, dirty сброшен |
| Закрытие без правок                     | вопроса нет                       |
| Закрытие с правками → Discard           | PJ не тронут                      |
| Закрытие с правками → Cancel            | диалог остался открыт             |
