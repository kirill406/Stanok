## 1. Назначение

Довести пакетные режимы до честных: `circular` реально ходит по кругу,
`constant` — повтор одной строки, оба с лимитом; resume фиксируется в отчёте;
имена файлов из любых полей (FR-6) покрыты тестами. Убрать дублирование
логики режимов между `resolve` и `generate` (сейчас окно строк для `constant`
собрано в сервисе вручную).

---

## 2. Архитектурные решения

### 2.1 `resolve_rows(..., limit)` — выборка переезжает в движок

```python
def resolve_rows(
    rows: list[dict[str, Any]],
    pj: ProjectJSON,
    today: date | None = None,
    limit: int | None = None,   # NEW, обратно совместимо
) -> tuple[list[FillingJSON], dict[str, int]]:
```

- `sequential`: `data[start : start+limit]`.
- `circular`: цикл по `data` до `limit` (без лимита — один круг, как сейчас).
- `constant`: повтор первой строки `limit` раз (без лимита — по числу строк).
- `limit <= 0` → `([], counters)` без ошибок.
- Нумерация `dist` (`{i}`) — с 1 внутри выборки, как сейчас.

### 2.2 `generate` упрощается

- Окно строк в сервисе остаётся (start, пропуск пустых, `max_docs<=0`),
  но mode-ветвление (`constant` отдельно) удаляется: сервис передаёт
  чистые строки + `limit=max_docs` в `resolve_rows`.
- Курсор `start_row` после прогона:
  - `sequential` — `start + len(окно источника)`;
  - `circular` — `start + len(data)` (съеден один круг; extra-круги reuse);
  - `constant` — `start + 1` (съедена первая непустая строка).
- Пустые строки по-прежнему пропускаются до движка (`skipped`, курсор идёт).

### 2.3 Resume в отчёте (FR-5)

- Курсор historic: `data_source.start_row` (без изменения схемы).
- `GenerateReport.resumed_from: int | None` — `None` при старте с 0,
  иначе значение курсора на входе.

### 2.4 Имена файлов (FR-6)

Новых плейсхолдеров не вводится: `{поле}`, `{i}`, `{template}` уже есть.
Фича = покрытие: константа/счётчик/today в `filename_template`,
кириллица и пробелы в значениях, неизвестный плейсхолдер → `ResolveError`
(уже), `..` → fail-fast (уже). Тесты фиксируют поведение.

## 4. Тестирование

| Сценарий                     | Ожидаемое поведение                 |
|------------------------------|-------------------------------------|
| circular 2 строки, limit 5   | 5 Filling: 1,2,1,2,1; счётчики +5   |
| circular без limit           | один круг (как раньше)              |
| constant limit 3             | 3 копии первой строки, счётчики +3  |
| limit 0 / отрицательный      | `[]`, без ошибок                    |
| generate circular + max_docs | `created == max_docs`, курсор +круг |
| resume с `start_row=2`       | `resumed_from == 2`                 |
| свежий старт                 | `resumed_from is None`              |
| dist из счётчика/today       | имя собрано, файл создан            |
| dist с `{Нетакого}`          | `ResolveError`                      |
