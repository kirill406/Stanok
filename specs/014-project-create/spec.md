# Спецификация: 014-project-create — Создание проекта (FR-12)

**Статус:** done
**Версия:** 0.1.0
**Фаза:** 4 (Управление проектами)
**Зависит от:** 005-core-storage (save, recent), 008-gui-main (кнопка «Создать»),
  004-core-render (`PLACEHOLDER_RE` из `xmlops`)
**FR:** FR-12
**NFR:** NFR-3, NFR-4

## 1. Цель

Кнопка «Создать проект» окна 1 — заглушка (`MAIN_CREATE_STUB`). FR-12 требует
полный флоу: выбор xlsx/docx → копирование в `Данные/`/`Шаблоны/` проекта
с чекбоксом «не копировать» → готовый PJ → проект в recent. После 014 новый
пользователь создаёт проект без ручной сборки папки.

## 2. Контракт

### 2.1 Диалог создания (окно 4, модальное из окна 1)

| Поле                         | Тип                          | Правило                                                                                       |
|------------------------------|------------------------------|-----------------------------------------------------------------------------------------------|
| Имя проекта                  | текст                        | stem конфига `<имя>.stanok`; пустое/занятое — ошибка в диалоге                                |
| Папка                        | выбор каталога               | default — последняя использованная; внутри создаются `Данные/`, `Шаблоны/`                    |
| Excel-файлы                  | список + «Добавить»/«Убрать» | ≥ 1 файл `.xlsx`; дубли — ошибка                                                              |
| DOCX-шаблоны                 | список + «Добавить»/«Убрать» | ≥ 1 файл `.docx`; дубли — ошибка                                                              |
| «Скопировать файлы в проект» | чекбокс, default вкл         | выкл = файлы уже лежат в `Данные/`/`Шаблоны/`, только связать (FR-12 «исключить копирование») |
| Кнопки                       | Создать / Отмена             | «Создать» неактивна, пока списки пусты или нет имени                                          |

### 2.2 Сервис `ProjectStore.init_project(...)`

```python
def init_project(
    self, folder: Path, name: str,
    xlsx: list[Path], docx: list[Path], copy_files: bool = True,
) -> ProjectJSON:
```

- Создаёт `Данные/`, `Шаблоны/`; при `copy_files` копирует файлы
  (`shutil.copy2`, имя при коллизии — суффикс `(1)` через общий `_unique_path`-подход);
  при выкл — проверяет, что файлы уже внутри, иначе ошибка.
- Строит PJ: `templates = {stem: {file, fields}}`,
  где `fields` — плейсхолдеры docx (`PLACEHOLDER_RE`) каждый → table-источник
  с именем колонки = именем плейсхолдера; `data_sources` — по одному
  sequential на xlsx; `counters = {}`; `filename_template = "{template}_{i}"`.
- Пишет PJ через `save()` (атомарно, 005), добавляет в recent, возвращает PJ.
- Ошибки — `StorageError` с понятным текстом (диалог показывает, не падает).

### 2.3 Окно 1

`_on_create` открывает окно 4 вместо стаба; после успеха — `refresh_recent()`.
`MAIN_CREATE_STUB` удаляется из STRINGS (замена на строки окна 4, NFR-3).

### 2.4 Строки окна 4 (STRINGS, NFR-3)

`CRT_TITLE`, `CRT_NAME`, `CRT_FOLDER`, `CRT_BROWSE`, `CRT_XLSX`, `CRT_DOCX`,
`CRT_ADD`, `CRT_REMOVE`, `CRT_COPY`, `CRT_CREATE`, `CRT_CANCEL` + тексты ошибок
(пустое имя, имя занято, дубли файлов, файл вне проекта при выкл. копировании).

## 3. Ошибки (показ в диалоге, не падение)

- Имя пустое / конфиг `<имя>.stanok` уже есть в Home.
- Папка недоступна для записи; копирование оборвалось midway —
  уже скопированное остаётся (отката нет); повтор с тем же именем упрётся
  в «имя занято» — сначала другое имя или удаление конфига.
- Битый docx (не читается как zip): пропустить файл с ошибкой или прервать?
  Решение: прервать с указанием файла (тихий пропуск шаблонов опаснее).

## 4. Тесты (NFR-4)

`tests/services/test_storage.py`: копирование файлов + структура PJ + маппинг
плейсхолдеров; режим без копирования (файлы на месте — ок, снаружи — ошибка);
коллизия имён при копировании; дубли/занятое имя.
`tests/gui/`: offscreen-тест окна 4 (заполнение → проект создан → recent обновлён).

## 5. Вне скоупа

- Смена типа поля после создания (table → counter/constant; отдельная спека).
- Удаление шаблона/проекта (FR-13, спека 015).
- Мастер-настройка соответствий «плейсхолдер ↔ колонка» (имена 1:1 по умолчанию).
