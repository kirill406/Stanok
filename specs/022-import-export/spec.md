# Спецификация: 022-import-export — Импорт .stanok и создание проекта из папки

**Статус:** done
**Версия:** 0.1.0
**Фаза:** 7 (GUI)
**Зависит от:** 020-field-sources (окно выбора проекта), 021-counters (формат PJ)
**FR:** FR-12, FR-13
**NFR:** NFR-3, NFR-4

## 1. Цель

Упростить перенос готовых проектов и открытие проекта, у которого нет
конфига в Home:

- в окне «Открыть проект» кнопка «Выбрать папку»;
- если в папке или подпапках рекурсивно есть `*.stanok` — перенести их в Home,
  проверить путь проекта, добавить валидные проекты в recent и показать
  количество импортированных;
- если конфигов нет, но папка похожа на проект (`Данные`, `Шаблоны`,
  `Результат`) — открыть окно создания с заполненными именем, базовой папкой
  и файлами;
- иначе — предупреждение.

## 2. Контракт

### 2.1 Импорт конфигов

```python
ProjectStore.import_configs(folder: str | Path) -> ImportReport

ImportReport:
    imported: list[str]       # имена конфигов в Home
    failed: list[str]         # имена нечитаемых/несохранённых файлов
    missing_folder: list[str] # импортированы, но папка проекта не найдена
    found: int                # найдено внешних *.stanok
```

- Поиск рекурсивный (`rglob("*.stanok")`), конфиги уже внутри Home пропускаются.
- Валидный PJ сохраняется в Home под исходным stem; при занятом имени —
  `stem (1)`, `stem (2)` и т. д.
- Папка проекта: существующий `PJ.folder`; иначе ближайшая папка исходного
  конфига (или её предок) с `Данные/` и `Шаблоны/`. Найденный путь записывается
  в PJ.
- Исходный `.stanok` удаляется только после успешного сохранения в Home.
- В recent добавляются только проекты с найденной папкой; остальные попадают
  в `missing_folder` и остаются доступны для «указать новую папку».
- Нечитаемый конфиг не переносится и попадает в `failed`.

### 2.2 Создание из папки

```python
detect_project_layout(folder) -> ProjectLayout | None
ProjectLayout: folder, xlsx (Данные/*.xlsx), docx (Шаблоны/*.docx)
```

Layout валиден только при наличии всех трёх подпапок:
`Данные`, `Шаблоны`, `Результат`.

Окно создания получает:

- имя проекта = имя выбранной папки;
- базовая папка = родитель выбранной папки (проект создаётся в
  `<родитель>/<имя>`, то есть в выбранной папке);
- списки xlsx/docx из `Данные`/`Шаблоны`;
- «Копировать файлы» включено.

Пользователь может изменить любые параметры до создания. Если файл уже лежит
в целевой подпапке проекта, `init_project` использует его без копирования
(не появляется `data (1).xlsx`).

### 2.3 UI

- Кнопка «Выбрать папку» в `QDialogButtonBox` окна «Открыть проект».
- После импорта список проектов перечитывается, выбирается первый импорт.
- Сообщение: «Добавлено проектов: N»; при ошибках/пропавших путях —
  дополнительные строки.
- После создания из layout окно выбора закрывается с принятием, окно 1
  открывает созданный проект и подсвечивает новые элементы.

## 3. Ограничения

- Импортируются только `.stanok`; другие файлы не трогаются.
- Конфиг без валидной папки не теряется, но и не попадает в recent.
- Все пользовательские строки — в `gui/strings.py`.
